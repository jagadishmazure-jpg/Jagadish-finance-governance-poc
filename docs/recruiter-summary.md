# Recruiter summary

- Problem: finance teams are offered AI tools faster than they can judge
  them, so weak, costly, or unauditable ideas can reach deployment.
- Approach: a small offline toolkit that scores an idea on three
  pillars, prices its model calls, reviews its security checklist,
  weighs building against buying, and grades its evidence — all before
  anyone approves a launch.
- Proof: 72 tests, all passing on system Python with no third-party
  packages, including named tests for every enforcement claim in the
  README. Every number below comes from an actual run of this code.
