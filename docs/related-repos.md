# Related repos (cross-links, not duplication)

This repo is one of a finance-focused set. Overlaps are linked here
instead of re-built here:

- Finance sentiment analysis: text signals for investment and credit
  work; this repo does not analyse text, it governs ideas that might.
- Finance compliance RAG: auditable retrieval for due-diligence
  work; its audit trail is the kind of evidence this repo's grader
  would ask for at the live grade.
- Finance KYC/AML pipeline: customer checks with audit trails;
  shares the evidence-grade idea, applied to a pipeline, not to
  governance in general.
- Finance credit memo: explainable underwriting narratives; its
  clarity-of-reasoning work is one pillar of this repo's scorecard.
- Finance portfolio risk agent: live risk monitoring; a monitoring
  agent would itself be scored and graded by this repo before launch.
- Finance bank-in-a-box: multi-agent coordination across finance
  functions; this repo would govern each of its agents as initiatives.
- Finance invoice reimbursement: document extraction and policy
  matching; the worked example here uses an invoice helper as its
  synthetic case, but builds no extraction logic.
- Finance data validation: checks on finance data quality; data
  quality evidence feeds this repo's record-keeping pillar.
- Fraud detection agents (existing portfolio): fraud patterns
  including organised rings; fraud controls are a security input to
  this repo's checklist, not a duplicate of it.

No code is copied between these repos in this scaffold; the links
above describe boundaries only.
